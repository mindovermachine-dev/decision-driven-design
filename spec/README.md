**Charter.** These documents define file formats. They are not canon: they say how a file is shaped, not what the framework holds true. Their force comes from the decision that ruled each one.

| File | Format |
|---|---|
| `claim-format.md` | Claim and decision files under `core/` |
| `doc-format.md` | Every other document: the `ddd:charter` folder charter and the `ddd:doc` opener |
